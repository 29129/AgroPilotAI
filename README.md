# AgroPilot AI

AgroPilot AI es una plataforma de apoyo a decisiones para pequeños y medianos productores agrícolas. Reúne información de fincas, parcelas, cultivos, clima, mercado e imágenes de campo para transformar datos dispersos en recomendaciones claras y trazables.

## Objetivo

Ayudar al productor o técnico a tomar mejores decisiones sobre riego, nutrición, sanidad y comercialización. El sistema no sustituye el criterio humano: cada recomendación presenta evidencia, nivel de confianza, explicación y acciones que requieren aprobación antes de considerarse completadas.

## Qué ofrece

- Registro y gestión de fincas, parcelas y cultivos.
- Diagnóstico preliminar de imágenes con revisión técnica.
- Consulta de clima y precios de mercado.
- Análisis multiagente con recomendaciones explicables.
- Planes semanales de trabajo y seguimiento de acciones.
- Conversaciones con un asistente agrícola y notificaciones.

El proyecto está organizado para que frontend y backend puedan evolucionar en paralelo mediante un contrato de API versionado.
